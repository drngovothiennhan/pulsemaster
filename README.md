# PulseMaster Pro – chẩn mạch YHCT (lực ấn + haptic)

**Đọc `HANDOFF.md` trước** (hiện trạng, quyết định, việc còn lại).

- `web/` – **PWA (bản chính)**: cài trên Android qua Chrome, chạy offline. Xem `web/README.md`.
- `core/` – lõi Kotlin kiểm thử được (`gradle -p core test`); `android/` – app Android (đang có lỗi, xem HANDOFF §6).
- `data/tcm_28_pulses_haptic.json` – 28 bộ mạch (nguồn dữ liệu duy nhất). `docs/` – kiến trúc, giao thức BLE, build.
